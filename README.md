# Raccoon Coefficient

**Number go up, brrr.**

Displays a Gear Score for worn equipment and a projected score change when hovering equippable items.

Locked v1 scores equipment stats. Optional Experimental E1 estimates selected set and weapon effects using assumptions; it is not a boss-specific performance calculator. A question mark indicates incomplete data. The preview accounts for equipment swaps including two-handed weapons and shields. The plugin does not read or store bank contents.

Build with `./gradlew clean build` and launch with `./gradlew run`.
